# Support

Thanks for using **Masum Galaxy // CP Arena**.

## Before reporting an issue

Please include:

- VS Code version
- Operating system
- CP Arena version
- Language being run (C, C++, Python, or JavaScript)
- Compiler/runtime version when relevant
- Exact error message
- Minimal source/input that reproduces the issue

For C/C++ runner issues, also include the output of:

```text
g++ --version
gcc --version
```

On Windows, `where.exe g++` can help confirm which compiler CP Arena is using.

## AI Coach issues

AI Coach requires a model exposed through the VS Code Language Model API. If AI actions report that no model is available, confirm that your VS Code Chat/model provider is active. GitHub Copilot users should verify that Copilot is signed in and enabled.

## Security

Do not post API keys, access tokens, passwords, private source code, or other secrets in public issues.
